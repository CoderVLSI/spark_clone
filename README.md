# PokePlant website + web flasher

This repository contains:

- `firmware/` — PlatformIO project for Seeed Studio XIAO ESP32-C6
- `site/` — responsive project website and ESP Web Tools installer
- `.github/workflows/build-and-pages.yml` — compiles the firmware, merges the ESP32-C6 images, and deploys the HTTPS flasher to GitHub Pages

## Publish the flasher

1. Push to the `main` branch.
2. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the source.
3. Wait for the workflow to finish. The Pages URL becomes the working installer.

The installer must be served over HTTPS. Open it in a Chromium-based browser with Web Serial support.

## Local preview

```bash
cd site
python3 -m http.server 8000
```

Localhost can preview the design, but the bundled firmware binary is generated by GitHub Actions.

## Customize hardware

Edit `firmware/include/config.h`, then push again. The workflow rebuilds and republishes the flasher automatically.
